# LowMemoryLLM

在资源受限设备上以完整精度和高速度运行大语言模型的框架。

[English Documentation](./README.md)

---

## 概述

LowMemoryLLM 旨在使大语言模型（70B+ 参数）能够在低端硬件（老旧手机、过时显卡、小内存设备）上运行，同时保持：

- **完整精度**：输出与 FP32/FP16 推理比特级一致
- **高速度**：接近原生推理性能
- **最小内存**：运行超出可用 RAM/VRAM 的模型

这需要开发超越现有优化技术的新算法。

---

## 问题陈述

| 约束 | 现有方案 | 局限性 |
|------|---------|--------|
| 内存 | 量化 (INT4/INT8) | 精度损失 |
| 内存 | 模型剪枝 | 准确度下降 |
| 速度 | 更小的模型 | 能力降低 |
| 速度 | 知识蒸馏 | 不是运行原始模型 |

**我们的目标**：通过新的算法方法，同时实现速度、精度、低内存三者兼顾。

## 研究方向

### 1. 神经子空间投影 (Neural Subspace Projection)

发现模型权重中的低维结构，按需动态合成权重，而非完整存储。

- 假设：模型知识存在于压缩流形中
- 方法：将权重分解为紧凑基底 + 输入相关系数
- 目标：10倍内存降低，零精度损失

### 2. 输入自适应动态计算 (Input-Adaptive Dynamic Computation)

并非所有输入都需要完整模型容量。根据输入难度自动确定计算复杂度。

- 简单查询 → 最小计算路径
- 复杂查询 → 完整模型参与
- 无需对现有模型重新训练

### 3. 预测性异步流水线 (Predictive Asynchronous Pipeline)

基于注意力模式预测未来计算路径，完全重叠 I/O 和计算。

- 分析注意力模式预测权重访问
- 在需要之前预取权重
- 目标：零有效内存延迟

### 4. 跨请求计算复用 (Cross-Request Computation Reuse)

构建语义计算缓存，识别输入之间的相似性，复用中间计算。

- 缓存 KV 状态和中间激活值
- 跨请求的语义相似性匹配
- 在相似查询间分摊计算成本

### 5. 无损自适应精度 (Lossless Adaptive Precision)

每个 token、每层动态选择精度，数学上保证精度保持。

- 不是量化，而是智能计算调度
- 关键计算使用高精度
- 数学上安全的地方使用低精度

## 目标性能

| 模型 | 设备 | 活跃内存 | 目标速度 | 精度 |
|------|------|---------|---------|------|
| LLaMA-2 7B | 手机 (4GB RAM) | <2GB | 10+ tokens/s | 无损 |
| LLaMA-2 70B | 笔记本 (16GB RAM) | <8GB | 2+ tokens/s | 无损 |
| Mixtral 8x7B | PC (8GB RAM) | <4GB | 5+ tokens/s | 无损 |
| 100B+ 模型 | 台式机 (32GB RAM) | <16GB | 1+ tokens/s | 无损 |

## 实现状态

### 已完成

- **硬件抽象层 (HAL)**
  - CPU 支持，带 AVX2/NEON 优化
  - GPU 支持，通过 OpenCL
  - 统一内存管理接口

- **量化基础设施**
  - INT8/INT4/FP16/FP8 量化
  - 按通道量化
  - 动态量化框架
  - 量化感知训练 (QAT)

- **KV 缓存管理**
  - 磁盘卸载
  - 滑动窗口旋转
  - 缓存压缩

- **混合精度训练**
  - 动态损失缩放
  - FP32 权重备份
  - 溢出检测

- **模型集成**
  - HuggingFace 模型加载器
  - 分词器 (BPE, WordPiece, Unigram, SentencePiece)

### 开发中

- **核心算法**
  - 神经子空间投影
  - 输入自适应动态计算
  - 预测性异步流水线
  - 跨请求计算复用

- **Transformer 实现**
  - 自注意力机制
  - 前馈网络
  - 层归一化
  - 完整推理流水线

- **内存管理**
  - 按层权重流式加载
  - 预测性预取
  - 带 LRU 淘汰的内存池

## 安装

```bash
git clone https://github.com/2404589803/LowMemoryLLM.git
cd LowMemoryLLM
mkdir build && cd build
cmake ..
make
```

## 环境要求

- 支持 C11 的 C 编译器
- CMake 3.10+
- (可选) OpenCL 用于 GPU 支持
- (可选) 支持 AVX2/NEON 的 CPU
